# Shell Emulator

Эмулятор командной оболочки UNIX-подобной ОС (вариант 9).

## Этап 1: REPL

- Интерактивный режим с приглашением `myvfs>`
- Команды-заглушки: `ls`, `cd`
- Команда `exit`
- Обработка ошибок: неизвестная команда, пустой ввод

## Запуск

    python src/main.py

## Пример работы

myvfs> ls test
ls: аргументы: ['test']
myvfs> foo
foo: команда не найдена
myvfs> exit
Выход из эмулятора
