## 1. Общее описание

Консольная программа, которая имитирует работу в командной строке
UNIX-подобной системы: показывает приглашение `myvfs>`, читает команды,
выполняет их и умеет проигрывать команды из стартового скрипта. При
выполнении скрипта на экране видно и ввод, и вывод, как в живом диалоге.

Проект разрабатывается по этапам, результат каждого этапа сохранён
отдельным коммитом.

**Технологии:** Python 3.8+, только стандартная библиотека
(устанавливать ничего не нужно).



### Структура репозитория

```
shell-emulator/
├── src/
│   ├── __init__.py
│   └── main.py                  # весь код эмулятора
├── tests/
│   ├── __init__.py
│   ├── test_parser.py           # тесты разбора ввода и параметров
│   ├── test_commands.py         # тесты команд
│   └── test_script.py           # тесты стартовых скриптов
├── scripts/
│   ├── start_ok.txt             # стартовый скрипт без ошибок
│   ├── start_error.txt          # стартовый скрипт с ошибкой

│   ├── test_script_param.bat    # демонстрация параметра --script
│   └── test_all_params.bat      # демонстрация без параметров и с обоими
├── run.bat                      # запуск эмулятора и тестов
├── .gitignore
└── README.md
```

## 2. Описание функций и настроек

### 2.1 Этап 1. REPL

**Цель.** Минимальный прототип: большинство команд пока заглушки, но
диалог с пользователем уже работает.

**Что реализовано**

| Требование | Как выполнено |
|------------|---------------|
| Консольный интерфейс (CLI) | программа запускается в терминале |
| Приглашение с именем VFS | `myvfs>` (имя задаётся константой `VFS_NAME`) |
| Парсер ввода | строка делится по пробелам на команду и аргументы |
| Заглушки `ls`, `cd` | печатают своё имя и список аргументов |
| Команда `exit` | завершает работу эмулятора |

**Как это работает.** Программа повторяет цикл
**ввод → разбор → выполнение → вывод**, пока не введена команда `exit`:

```
ввод строки  →  parse_line()  →  execute_command()  →  вывод результата
     ↑                                                        │
     └────────────────────────────────────────────────────────┘
```

Пример разбора: `ls -l папка1 папка2` → команда `ls`,
аргументы `['-l', 'папка1', 'папка2']`.

**Команды**

| Команда | Что делает сейчас |
|---------|-------------------|
| `ls [аргументы]` | заглушка: печатает `ls: аргументы: [...]` |
| `cd [аргументы]` | заглушка: печатает `cd: аргументы: [...]` |
| `exit` | завершает работу эмулятора |

**Обработка ошибок и особых случаев**

| Ситуация | Что делает программа |
|----------|----------------------|
| Неизвестная команда (`foo`) | выводит `foo: команда не найдена` и ждёт следующий ввод |
| Пустая строка | ничего не делает, снова показывает приглашение |

**Функции этапа**

| Функция | Что делает |
|---------|------------|
| `parse_line(line)` | делит строку на команду и аргументы; для пустой строки возвращает `(None, [])` |
| `cmd_ls(args)` | заглушка `ls` |
| `cmd_cd(args)` | заглушка `cd` |
| `execute_command(command, args)` | выполняет одну команду, возвращает `RESULT_OK`, `RESULT_ERROR` или `RESULT_EXIT` |
| `run_repl()` | интерактивный цикл «ввод → выполнение → вывод» |

### 2.2 Этап 2. Конфигурация

**Цель.** Сделать эмулятор настраиваемым: принимать параметры при запуске
и выполнять команды из стартового скрипта.

**Что реализовано**

| Требование | Как выполнено |
|------------|---------------|
| Параметры командной строки | `--vfs-path` и `--script` (модуль `argparse`) |
| Отладочный вывод параметров | при запуске печатаются все заданные значения |
| Стартовый скрипт | команды читаются из файла построчно |
| Комментарии в скрипте | всё после `#` игнорируется |
| Диалог при выполнении скрипта | на экран выводится и ввод (`myvfs> команда`), и результат |
| Сообщение об ошибке | неизвестная команда в скрипте и отсутствующий файл скрипта |
| Скрипты реальной ОС | три `.bat`-файла в `scripts/` |

**Параметры командной строки**

| Параметр | Значение | Обязательный |
|----------|----------|:------------:|
| `--vfs-path` | путь к физическому расположению VFS | нет |
| `--script` | путь к стартовому скрипту | нет |


**Константы-настройки** (в начале `src/main.py`)

| Константа | Значение | Назначение |
|-----------|----------|------------|
| `VFS_NAME` | `"myvfs"` | имя в приглашении к вводу |
| `COMMENT_CHAR` | `"#"` | символ начала комментария в скрипте |

**Формат стартового скрипта.** Обычный текстовый файл (UTF-8),
одна команда на строку:

```
# комментарий на отдельной строке
ls
ls -l папка1 папка2
cd папка1   # комментарий в конце строки
exit
```

Правила выполнения:

- пустые строки и комментарии пропускаются;
- при ошибочной команде выводится сообщение с именем файла и номером
  строки, а выполнение скрипта продолжается;
- если скрипт закончился без `exit`, эмулятор переходит в интерактивный режим.

**Функции этапа**

| Функция | Что делает |
|---------|------------|
| `parse_args(argv=None)` | читает параметры командной строки |
| `strip_comment(line)` | убирает комментарий и пробелы по краям строки |
| `run_script(path)` | выполняет скрипт, показывает ввод и вывод, сообщает об ошибках; возвращает `True`, если встретился `exit` |
| `print_config(config)` | печатает заданные параметры (отладочный вывод) |
| `main()` | точка входа: параметры → скрипт → интерактивный режим |

## 3. Сборка и запуск тестов

**Требования.** Python 3.8 или новее. Внешних библиотек нет.

**Сборка.** Не требуется: проект на Python запускается напрямую.

**Запуск эмулятора**

| Команда | Что делает |
|---------|------------|
| `run.bat` | интерактивный режим |
| `run.bat --script scripts\start_ok.txt` | выполнить скрипт, затем интерактивный режим |
| `python src/main.py --vfs-path vfs/test.zip --script scripts/start_ok.txt` | то же без `run.bat`, с двумя параметрами |

**Запуск тестов** (из корня проекта)

```
run.bat test
```

или напрямую:

```
python -m unittest discover -v
```

Ожидаемый результат: `Ran 19 tests ... OK`.

| Файл | Что проверяет | Тестов |
|------|---------------|:------:|
| `tests/test_parser.py` | разбор строки, параметры командной строки | 7 |
| `tests/test_commands.py` | `ls`, `cd`, `exit`, неизвестная и пустая команда | 5 |
| `tests/test_script.py` | вывод ввода и результата, комментарии, ошибки, `exit`, отсутствующий файл | 7 |

**Демонстрационные скрипты Windows** (запуск из корня проекта,
например `scripts\test_all_params.bat`)

| Файл | Что проверяет |
|------|---------------|
| `test_vfs_param.bat` | только `--vfs-path` |
| `test_script_param.bat` | только `--script`: нормальный скрипт, скрипт с ошибкой, несуществующий файл |
| `test_all_params.bat` | запуск без параметров и с обоими параметрами |

## 4. Примеры использования

### 4.1 Этап 1

```
myvfs> ls
ls: аргументы: []
myvfs> ls -l папка1 папка2
ls: аргументы: ['-l', 'папка1', 'папка2']
myvfs> cd папка1
cd: аргументы: ['папка1']
myvfs> foo
foo: команда не найдена
myvfs> exit
Выход из эмулятора
```

### 4.2 Этап 2

**Запуск с обоими параметрами** (`scripts/start_ok.txt`):

```
=== Параметры запуска ===
Путь к VFS: vfs\test.zip
Путь к стартовому скрипту: scripts\start_ok.txt
=========================
myvfs> ls
ls: аргументы: []
myvfs> ls -l папка1 папка2
ls: аргументы: ['-l', 'папка1', 'папка2']
myvfs> cd папка1
cd: аргументы: ['папка1']
myvfs> cd ..
cd: аргументы: ['..']
myvfs> exit
Выход из эмулятора
```

**Скрипт с ошибкой** (`scripts/start_error.txt`):

```
myvfs> ls
ls: аргументы: []
myvfs> foo аргумент
foo: команда не найдена
Ошибка в скрипте 'scripts\start_error.txt', строка 3: foo аргумент
myvfs> cd /
cd: аргументы: ['/']
myvfs> exit
Выход из эмулятора
```

**Скрипт не найден:**

```
Ошибка: не удалось открыть скрипт 'scripts\net_takogo.txt': [Errno 2] No such file or directory: 'scripts\\net_takogo.txt'
```
