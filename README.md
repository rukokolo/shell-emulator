# Shell Emulator

Эмулятор командной оболочки UNIX-подобной ОС (вариант 9).

## Этап 1: REPL

- Интерактивный режим с приглашением `myvfs>`
- Команды-заглушки: `ls`, `cd`
- Команда `exit`
- Обработка ошибок: неизвестная команда, пустой ввод

## Запуск

    python src/main.py

## Пример работы

myvfs> ls test
ls: аргументы: ['test']
myvfs> foo
foo: команда не найдена
myvfs> exit
Выход из эмулятора

## Этап 2: Конфигурация

Параметры командной строки:
- `--vfs-path` — путь к физическому расположению VFS
- `--script` — путь к стартовому скрипту (поддерживаются комментарии `#`)

При запуске выводятся все заданные параметры (отладочный вывод).

Пример запуска:

    python src/main.py --vfs-path vfs/test.zip --script scripts/start_ok.txt

Тестовые скрипты ОС лежат в папке `scripts/` (`*.bat`).
